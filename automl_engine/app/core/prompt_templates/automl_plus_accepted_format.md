# Accepted formats for AutoML+

- Image tools
  - For image to website tasks : You can submit an image file of any format and it will be converted to a website
  - To run a vision language tool on an image with a prompt - You may pass in an image file/URL and a string prompt
- Website Accessibility
  - For checking alt text, you can pass in a url for the image, and the alt text you want to check
  - To analyze a website - you may pass in an HTML file along with other extra files to give the LLM context, or you may pass in a URL
